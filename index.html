How the math works

A block at difficulty D costs D × 232 hashes on average. Your wait is that work divided by your hashrate: 

solo wait      = difficulty × 2³² ÷ hashrate
blocks per day = hashrate × 86,400 ÷ (difficulty × 2³²)
subsidy / day  = blocks per day × block subsidy

This is independent of how fast the rest of the network is currently producing blocks. Faster network block times do not change your expected hashes per block — only the live difficulty does.

TurboSHAKE256

RFC 9861 · runs in your browser

Twelve rounds. 256-bit strength.

TurboSHAKE256 is SHAKE256 with the Keccak permutation cut from 24 rounds to 12. Same rate, same capacity, about twice the speed in native code. This tab hashes locally — nothing is uploaded.

Rounds 12 SHAKE256 uses 24
Security 256-bit same target as SHAKE256
Rate 136 B 1,088 bits per block
Capacity 64 B 512 bits
Permutation Keccak-p 1600-bit state, 12 rounds
Domain byte 0x1F default, range 0x01–0x7F 

—

Output is extendable: a shorter digest is the prefix of a longer one. Defined in RFC 9861.

How the TSK miner works

turboshake256-miner is a separate experimental chain. Its token is TSK. Mining uses TurboSHAKE256. The BIP110 calculator on the other tab is a different network and mines with BLAKE2b.

  1. Build the block. The node packs a coinbase of 50 TSK plus fees, then any mempool transfers. The header fields are height, time, previous block hash, merkle root, and difficulty.
  2. Commit the header. Those fields are hashed with TurboSHAKE256 and domain byte 0x23. The nonce is not in this hash. The result is a 32-byte commitment.
  3. Search nonces. Each try appends an 8-byte little-endian nonce and hashes again with domain byte 0x24. CPU threads split the nonce space. A CUDA or OpenCL GPU can search the same job at the same time. The first valid nonce wins.
  4. Check the target. The 32-byte digest is a number. It is a valid proof of work when it is strictly below 2^(256 − difficulty). A higher difficulty means more leading zero bits and more hashes per block.
  5. Retarget. Difficulty is adjusted every 20 blocks so blocks land near 10 seconds. One adjustment can move difficulty by at most 4×, and it stays between 8 and 40 bits. The heaviest chain, measured as the sum of 2^difficulty, is the one nodes follow. 
commitment = TurboSHAKE256(header fields, D=0x23)
digest     = TurboSHAKE256(commitment ‖ nonce, D=0x24)
valid      = digest < 2^(256 − difficulty)

Spends are Ed25519 signatures. A tsk1 address is the first 20 bytes of TurboSHAKE256(public key) with domain 0x25. Domain bytes 0x06, 0x07, and 0x0B are left unused because KangarooTwelve reserves them.
